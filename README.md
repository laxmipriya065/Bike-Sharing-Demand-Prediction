# Bike Sharing Demand Prediction Using Machine Learning

## Project Overview
This project focuses on predicting the total number of bike rentals using Machine Learning. The Bike Sharing Demand dataset is analyzed to understand how factors such as temperature, humidity, weather, season, and time affect bike rental demand.

## Dataset Information
- **Dataset:** Bike Sharing Demand
- **File:** train.csv
- **Total Records:** 10,886
- **Total Features:** 12
- **Target Variable:** count
- **Problem Type:** Regression

## Objectives
- Understand and explore the dataset.
- Identify missing values, duplicate records, and outliers.
- Perform data cleaning and preprocessing.
- Visualize patterns and relationships in bike rentals.
- Build a Linear Regression model.
- Evaluate the model's prediction performance.

## Machine Learning Algorithm
**Linear Regression** is used to predict the total number of bike rentals (`count`) based on different input features.

The dataset is divided into:
- 80% Training Data
- 20% Testing Data

## Model Evaluation Metrics
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Key Findings
The project explores how bike rental demand changes according to:
- Different seasons and weather conditions.
- Temperature and humidity.
- Working days and non-working days.
- Different hours of the day.

## Conclusion
This project demonstrates how Exploratory Data Analysis and Machine Learning can be used to understand and predict bike rental demand. Linear Regression provides a baseline prediction model. Other algorithms, such as Random Forest and Decision Tree, can be explored in the future to improve prediction performance.
